## How to Update This Template

**After each practice test:**

1. **Overall section**: Update test number, latest score, change from previous test, gap to target (730 - current score)

2. **Domain table**: Calculate percentages for each domain:
   - Algebra: `(correct answers / total questions) × 100`
   - Advanced Math: `(correct answers / total questions) × 100`  
   - PSDA: `(correct answers / total questions) × 100`
   - Geometry: `(correct answers / total questions) × 100`

3. **Change column**: Compare to previous test (`new % - old %`, add `pp` for percentage points)

4. **Priority levels**:
   - CRITICAL: < 60%
   - HIGH: 60-74%
   - MEDIUM: 75-89%
   - LOW: 90%+

5. **Recommendations**: Update based on:
   - Critical/High priority domains
   - Domains that declined ≥10pp
   - Domains that improved ≥10pp
   - Current gap advice
