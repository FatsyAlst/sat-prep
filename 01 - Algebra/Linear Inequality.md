# Linear Inequality

## Core Rule

> **When you multiply or divide both sides by a negative number, FLIP the inequality sign.**

$$-2x > 6 \implies x < -3$$

---

## Solving Linear Inequalities

Treat like an equation, but watch for sign flips.

**Example:**
$$5 - 3x \leq 14$$
$$-3x \leq 9$$
$$x \geq -3 \quad \text{(flipped because ÷ by } {-3}\text{)}$$

---

## Compound Inequalities

### AND (Intersection) — both must be true
$$-2 < x + 1 \leq 5$$
$$-3 < x \leq 4$$
Solution: $x \in (-3, 4]$

> AND → the overlap of both solution sets

### OR (Union) — at least one must be true
$$x < -1 \quad \text{or} \quad x > 3$$
Solution: $x \in (-\infty, -1) \cup (3, \infty)$

> OR → the combined solution sets

---

## Absolute Value Inequalities

### Less than (AND)
$$|ax + b| < c \quad \implies \quad -c < ax + b < c$$

**Example:** $|2x - 1| < 5 \implies -5 < 2x - 1 < 5 \implies -2 < x < 3$

### Greater than (OR)
$$|ax + b| > c \quad \implies \quad ax + b < -c \quad \text{or} \quad ax + b > c$$

**Example:** $|x + 3| \geq 7 \implies x + 3 \leq -7 \text{ or } x + 3 \geq 7 \implies x \leq -10 \text{ or } x \geq 4$

> **Memory aid:** Less thAND, GreatOR

## Interval Notation

| Inequality | Interval | Number Line |
|------------|----------|-------------|
| $x > a$ | $(a, \infty)$ | Open circle at $a$, arrow right |
| $x \geq a$ | $[a, \infty)$ | Closed circle at $a$, arrow right |
| $x < b$ | $(-\infty, b)$ | Arrow left, open circle at $b$ |
| $a \leq x < b$ | $[a, b)$ | Closed at $a$, open at $b$ |

## Inequalities in Two Variables

$$y > mx + b \quad \text{→ shade ABOVE the dashed line}$$
$$y \leq mx + b \quad \text{→ shade BELOW the solid line}$$

| Symbol | Line | Shade |
|--------|------|-------|
| $>$ or $<$ | **Dashed** (boundary not included) | Above ($>$) or below ($<$) |
| $\geq$ or $\leq$ | **Solid** (boundary included) | Above ($\geq$) or below ($\leq$) |

**Test point method:** Pick a point not on the line (usually $(0,0)$). Plug in:
- If the inequality is true → shade the side containing the test point
- If false → shade the other side

## Word Problems with Inequalities

Look for keywords:
| Keyword | Symbol |
|---------|--------|
| at most, no more than, maximum | $\leq$ |
| at least, no less than, minimum | $\geq$ |
| fewer than, less than | $<$ |
| more than, greater than | $>$ |

**Example:**
*"A student needs at least 80 points to pass. Each correct answer is worth 4 points. If the student already has 20 points, how many more correct answers $n$ are needed?"*
$$20 + 4n \geq 80 \implies n \geq 15$$

## SAT Tips

1. **The #1 mistake is forgetting to flip the sign** — watch for multiplying/dividing by negatives
2. **Absolute value = distance from zero** — $|x - 3| < 5$ means "$x$ is within 5 units of 3"
3. **When a problem says "which inequality represents..."**, test a value that should work and plug into each answer choice
4. **Systems of inequalities** on the SAT usually ask for a point in the solution region — test each answer choice
5. **"No solution" for $|x| < \text{negative}$** — absolute value is never negative, so $|x| < -2$ has no solution
6. **"All real numbers" for $|x| > \text{negative}$** — $|x| > -3$ is always true
