## What the SAT Tests

- Using ratios, rates, proportional relationships, and units to solve problems
- Analyzing and interpreting data presented in various forms
- Finding and using probabilities
- Understanding statistical concepts: sampling, margin of error, confidence

## Key Skills

- Set up and solve proportions: $\frac{a}{b} = \frac{c}{d}$
- Percent change: $\frac{\text{new} - \text{old}}{\text{old}} \times 100$
- Mean, median, mode, range, standard deviation (conceptual)
- Read scatterplots, bar charts, histograms, two-way tables
- Calculate probability: $P = \frac{\text{favorable outcomes}}{\text{total outcomes}}$
