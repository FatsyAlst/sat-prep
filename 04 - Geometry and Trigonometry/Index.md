## What the SAT Tests

- Solving problems using area, volume, and surface area formulas
- Using properties of lines, angles, triangles, and circles
- Applying right triangle trigonometry (sin, cos, tan)
- Working with circles in the coordinate plane
- Using the Pythagorean theorem

## Key Formulas

| Shape | Area | Other |
|-------|------|-------|
| Triangle | $A = \frac{1}{2}bh$ | Pythagorean: $a^2 + b^2 = c^2$ |
| Rectangle | $A = lw$ | Diagonal: $d = \sqrt{l^2 + w^2}$ |
| Circle | $A = \pi r^2$ | Circumference: $C = 2\pi r$ |
| Cylinder | — | $V = \pi r^2 h$ |
| Sphere | $SA = 4\pi r^2$ | $V = \frac{4}{3}\pi r^3$ |
| Cone | — | $V = \frac{1}{3}\pi r^2 h$ |

**Trigonometry:**
$$\sin\theta = \frac{\text{opposite}}{\text{hypotenuse}}, \quad \cos\theta = \frac{\text{adjacent}}{\text{hypotenuse}}, \quad \tan\theta = \frac{\text{opposite}}{\text{adjacent}}$$
